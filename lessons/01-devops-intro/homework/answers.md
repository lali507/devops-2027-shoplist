# שיעור 1: תרגול

## 1. ציור ארכיטקטורה

```
Browser → frontend (Nginx :80) → backend (Flask :5000) → postgres (PostgreSQL :5432)
                 ↓                  ↑
                 stats (Node.js :3000)
```

| סרוויס | פורט | תפקיד |
|---|---|---|
| frontend (Nginx) | 80 | מגיש את האתר לדפדפן ומעביר את בקשות ה-API ל-backend ול-stats. |
| backend (Flask) | 5000 | ה-API של המוצרים: הוספה, עריכה, מחיקה וקריאה מהמסד. |
| stats (Node.js) | 3000 | מבקש את רשימת המוצרים מ-backend ומחשב ממנה סטטיסטיקות. |
| postgres (PostgreSQL) | 5432 | שומר את המוצרים. |

## 2. פירוק מונוליט: חנות אונליין

**סרוויסים:** משתמשים, מוצרים, הזמנות, תשלומים ומיילים, ולכל אחד אחריות אחת והנתונים שלו.

**מי מדבר עם מי:**
- הדפדפן מדבר עם frontend או שער API אחד, והוא מעביר את הבקשות לסרוויס המתאים.
- הזמנות פונה למשתמשים כדי לזהות את הלקוח, ולמוצרים כדי לבדוק מחיר ומלאי.
- הזמנות פונה לתשלומים כדי לחייב את הלקוח.
- הזמנות פונה למיילים כדי לשלוח אישור הזמנה.

**מה קורה אם התשלומים נופלים?** אי אפשר להשלים תשלום, אבל שאר החנות ממשיכה לעבוד: אפשר להתחבר, לעיין במוצרים ולמלא סל. אפשר לשמור הזמנה במצב "ממתינה לתשלום" ולהשלים אותה כשהסרוויס חוזר.
